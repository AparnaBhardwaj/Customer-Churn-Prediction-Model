# Customer-Churn-Prediction-Model

**End-to-end ML project predicting customer churn.**  
Predicts whether a customer will leave using data preprocessing, feature engineering, model training, evaluation, and deployment.

## Features
- Data preprocessing & EDA  
- Model training & evaluation (Accuracy, Precision, Recall, F1-Score)  
- Saved model (`model.pkl`) for deployment  
- Real-time predictions via `app.py` (Flask/Streamlit)

## Tech Stack
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | Flask/Streamlit  

## Dataset
`customer_data.csv` – includes customer demographics, account info, and service usage metrics
